The local/desktop OpenCode harness source in `_wt-orch-build` now projects an optional `native_usage` record into local task snapshots. It takes the latest qualifying assistant message in the task's root session and follows the pinned OpenCode v1.18.34 sidebar formula: input, output, reasoning, cache-read and cache-write tokens divided by the matching provider/model context limit. The record is scoped to the task and root session, and excludes child sessions. Missing token fields or a matching model limit remain unavailable. Repeated snapshots replace the same message record rather than accumulating it.
