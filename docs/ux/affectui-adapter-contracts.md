## Wrapper API mapping and controller assertions

`UI/button.buttonVariants` keeps its cva/VariantProps-compatible callable signature `{variant?,size?,className?} → string`. It returns `ui-buttonc`, the mapped upstream variant/size classes, wrapper variant/size classes and caller classes. Explicit `type` wins. Slot receives no injected button type. `asChild` requires one element and preserves Radix Slot's child-first handler merging, child ref and attributes; it never wraps a link in a button. Disabled links retain their current caller semantics; do not manufacture an href or navigation handler.
