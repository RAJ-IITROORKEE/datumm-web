# OpenCode OC-2 theme provenance

`oc-2.json` is copied verbatim from OpenCode commit `b4866520679e7a74c688223b30356d1c29f18e4f` at `packages/ui/src/theme/themes/oc-2.json`.

Source: https://github.com/anomalyco/opencode/blob/b4866520679e7a74c688223b30356d1c29f18e4f/packages/ui/src/theme/themes/oc-2.json

The upstream MIT notice is retained in this directory's `LICENSE.txt` (Copyright 2025 opencode). DATUMM maps the OC-2 light/dark palette and surface overrides to its existing semantic CSS roles in `appearance.ts`; it does not import OpenCode's Solid theme provider or resolver. The existing `opencode.json` remains available as the legacy OpenCode TUI palette.
