# DATUMM Web

Browser dashboard for the DATUMM architectural assistant. This repository is being prepared from the approved desktop interface, with browser authentication and a separately installed Revit connector.

The web dashboard and Windows desktop will share the configured Clerk identity service. Desktop-only privileges are not exposed through a browser adapter. Hosting configuration, account secrets, model keys, user data and installer binaries do not belong in this repository.

Release status: implementation and verification in progress. A deployed interface alone does not qualify model execution, Google sign-in or native Revit operations.
